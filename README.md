# TuolaFlow

在 VS Code 中使用看板整理任務。

## 開啟看板

- 點選左側 Activity Bar 的 TuolaFlow 圖示。
- 也可以在命令面板執行「TuolaFlow: 開啟任務看板」。

## 管理任務

- 按狀態欄旁的「+」新增任務，或點選「新增任務」選擇狀態。
- 點選任務卡片編輯內容；可設定標題、描述、標籤、狀態、優先序和到期日。
- 拖曳卡片可調整順序或移至其他狀態。
- 開啟卡片選單可複製或刪除任務。
- 使用狀態欄的排序選單，依標題、到期日或優先序排列任務。

## 搜尋任務

點選看板上方的搜尋按鈕，或在看板開啟時按 `Ctrl+F`，輸入標題搜尋任務。

## 管理看板

開啟看板上方的管理選單，可新增、編輯或刪除狀態與標籤，也可選擇看板資料檔案。
